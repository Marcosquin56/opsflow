# OpsFlow

OpsFlow es una demo interactiva de gestión de solicitudes empresariales. El
proyecto muestra un flujo completo de soporte y operaciones: priorización,
asignación, seguimiento de SLA, roles y métricas.

## Funcionalidades

- Dashboard operativo con indicadores y actividad reciente.
- Bandeja con búsqueda y filtros por estado.
- Creación de solicitudes de demostración.
- Cambio de estado e historial de actividad.
- Vistas adaptadas para administrador, analista y solicitante.
- Pantallas de equipo y métricas.
- Diseño responsive para escritorio, tablet y móvil.

## Ejecutar localmente

```bash
pnpm install
pnpm dev
```

Los datos son completamente ficticios y permanecen solamente durante la sesión
del navegador. Una versión futura puede incorporar persistencia con una base de
datos y autenticación real.
