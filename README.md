# OpsFlow

Demo interactiva de una aplicación de gestión de solicitudes empresariales, creada por Marcos Quintana como proyecto de portfolio.

## Funcionalidades

- Dashboard con indicadores operativos.
- Búsqueda y filtros de solicitudes.
- Creación y actualización de solicitudes.
- Cambio de roles para explorar diferentes permisos.
- Vistas de equipo y métricas.
- Diseño responsive para escritorio y móvil.

## Tecnologías

React, TypeScript, Vite, CSS y GitHub Pages.
